# Yapper rules

Yapper reads this note before sorting every capture. Edit it in Obsidian to change where things go.

## Sections
- Tabby/ — my DevOps internship: my tasks, what I learned, questions for my team.
  Never store internal company data, secrets or customer info here.
- Uni/ — one note per course (e.g. Uni/Algorithms.md, Uni/Operating Systems.md).
  Exams, assignments, lecture notes.
- Research/ — research assistant work (Accessible Places).
- Projects/ — one note per project (Daftar, Sadeem, KStack, Yapper, ...).
- Club/ — Programming Club.
- Personal/ — everything else.
- Daily/ — daily notes, YYYY-MM-DD.md (plans, debriefs).

## Second brain
- Keep a note per person (People/), project (Projects/), course (Uni/) and tool/company/topic (Topics/).
  Tabby itself → Tabby/Tabby.md.
- Link everything with [[wikilinks]].

## Routing
- Prefer appending to an existing note over creating a new one.
- Anything with a time → reminder, plus a line in today's daily note.
- Not sure where it goes → Inbox.md with a one-line question.

## Format
- Append under a dated heading.
- Tasks use "- [ ]".
- Keep my wording for ideas. Remove filler words.
